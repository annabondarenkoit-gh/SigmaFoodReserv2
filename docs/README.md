# SigmaFood — система шкільного харчування

Telegram-бот з Web App для замовлення шкільного харчування.
Стек: **Python (aiogram 3) + FastAPI + Google Sheets + Gemini API**, хостинг **Railway**.

## Архітектура

```
                    ┌─────────────────────────────┐
   Батьки ─────────▶│  Telegram Bot + Web App     │
   Вчителі ────────▶│  (єдиний FastAPI-сервіс      │──▶ Google Gemini API
   Адмін ──────────▶│   на Railway)               │      (парсинг PDF-меню)
                    └──────────────┬──────────────┘
                                   │
                                   ▼
                    ┌─────────────────────────────┐
                    │  Google Sheets              │
                    │  (папка SigmaFoodRezerv)    │
                    │  4 аркуші:                  │
                    │  База_Меню · Довідник       │
                    │  База_замовлень · Для кухні │
                    └─────────────────────────────┘
```

## Ролі (ієрархія)

- **Адмін** — вписаний вручну (`ADMIN_CHAT_ID`). Завантажує PDF-меню, робить розсилку, /report, додає вчителів.
- **Вчитель** — доданий адміном. Додає учнів свого класу, бачить статуси, отримує сповіщення.
- **Батьки** — прив'язані вчителем (до 2 chat_id на учня). Обирають страви у Web App. Обидва контакти працюють спільно.

## Структура файлів

```
app/
  config.py                 # секрети зі змінних оточення, константи
  main.py                   # FastAPI: webhook + Web App API + статика
  handlers/__init__.py      # команди бота (усі ролі)
  services/
    sheets.py               # Google Sheets: 4 аркуші, CRUD
    gemini_parser.py        # парсинг PDF (без «Полуденка»)
    deadline.py             # блокування о 00:00 (Київ)
    report.py               # генерація .xlsx-звіту
    notify.py               # ролі + сповіщення
webapp/
  index.html                # Web App батьків (чекліст страв)
requirements.txt · Procfile · runtime.txt
```
